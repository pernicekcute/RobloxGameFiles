# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability or an issue with any scripts or `.rbxl` files provided in this repository, please report it by opening an issue or contacting the maintainer directly. 

## Source Code and Obfuscation

All Lua scripts provided in this repository are processed and obfuscated using IronBrew to protect the source code and ensure integrity. Attempting to de-obfuscate or reverse engineer these scripts is strictly discouraged.
